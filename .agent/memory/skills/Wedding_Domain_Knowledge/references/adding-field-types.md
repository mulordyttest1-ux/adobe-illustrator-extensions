# Adding New Field Types

## Checklist

1. [ ] Define the field in the owning schema or shared domain layer
2. [ ] Add the field definition to the current data structure
3. [ ] Decide the sync mode
4. [ ] Add dedicated business processing when needed
5. [ ] Document any derived-field contract clearly
6. [ ] Update UI rendering if the field does not use the default renderer path
7. [ ] Verify the update path into Illustrator
8. [ ] Update reverse sync if the field may be scanned back
9. [ ] Add a reusable note to the nearest repo doc or reference file if the pattern should be reused later
